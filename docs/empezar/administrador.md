# Soy administrador

Desde el **BackOffice** dejás GDI listo para tu municipio: los datos del municipio, el organigrama, quién es quién y qué documentos se usan. Elegí cómo querés aprender.

<div class="grid cards gdi-formas" markdown>

-   :material-play-circle-outline:{ .gdi-forma-icono } **Ver videos**

    Un video por pantalla del BackOffice, en el orden en que conviene configurarlo.

    [Ir a los videos](#videos)

-   :material-chat-question-outline:{ .gdi-forma-icono } **Preguntarle a una IA**

    Por ejemplo: «¿cómo hago para que solo el intendente firme decretos?». Se abre en NotebookLM, de Google.

    [Preguntarle a la IA](https://notebooklm.google.com/notebook/56b820d3-ef1d-403f-bbd2-aa2710e5bdd4){ target="_blank" rel="noopener" }

-   :material-book-open-variant:{ .gdi-forma-icono } **Leer la guía**

    Todas las pantallas del BackOffice, con lo que hace cada opción.

    [Abrir la guía](../administradores/index.md)

</div>

## Por dónde empezar

Si recién arrancás, seguí este orden:

1. [Los datos y el logo del municipio](../administradores/informacion-general.md)
2. [El organigrama: reparticiones y sectores](../administradores/organigrama.md)
3. [Los rangos y los sellos de firma](../administradores/roles-y-sellos.md)
4. [Los usuarios](../administradores/usuarios.md)
5. [Los tipos de documento](../administradores/tipos-de-documentos.md) y [los tipos de expediente](../administradores/tipos-de-expedientes.md)
6. [Los certificados de firma digital](../administradores/certificados.md)

Para la parte legal (ordenanza de adhesión, decreto, puesta en marcha) está la [guía de implementación](../administradores/implementacion/index.md).
