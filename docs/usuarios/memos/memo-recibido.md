# Memo Recibido

Cuando abrís un memo que recibiste, el sistema registra automáticamente la apertura. Esta información es visible para el remitente.

---

## Vista del receptor

### Primera apertura

La primera vez que abrís un memo recibido, se muestra un badge **"Primera vez que abrís este memo"**. A partir de ese momento, el remitente puede ver que lo abriste y cuando.

### Contenido

- **PDF del memo** firmado
- **Información del remitente**: nombre completo y sector
- **Fecha de firma**

### Panel de destinatarios

Ves los destinatarios del memo:

| Grupo | Que ves |
|-------|---------|
| **Para (TO)** | Nombre completo y sector |
| **CC** | Nombre completo y sector |
| **CCO (BCC)** | No visible (solo el remitente los ve) |

### Resumen IA

Si el sistema generó un resumen automático, se muestra para lectura rápida.

---

## Archivar un memo

Para mantener limpia tu bandeja de recibidos, podés archivar memos:

1. Abrí el memo
2. Presiona el botón **"Archivar"**
3. El memo se mueve a la pestaña **Archivados**

### Desarchivar

Si necesitás volver a ver un memo archivado en tu bandeja:

1. Anda a la pestaña **Archivados**
2. Abrí el memo
3. Presiona **"Desarchivar"**
4. El memo vuelve a **Recibidos**

!!! info "Archivar es personal"
    Archivar un memo solo lo mueve de TU bandeja. Los demás destinatarios siguen viéndolo en sus bandejas normalmente. El remitente no se entera de que lo archivaste.

!!! info "Solo destinatarios pueden archivar"
    El remitente no puede archivar sus propios memos enviados. Solo los destinatarios (TO, CC, CCO) pueden hacerlo.
