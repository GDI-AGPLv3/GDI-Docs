# Tipos de Expediente

El sistema incluye **30 tipos de expediente** globales. Cada organización habilita su propia selección a partir de este catálogo. El tipo de expediente define la **trata** (categoría del trámite) y aparece en el número oficial del expediente.

!!! info "Disponibilidad por organización"
    Cada organización habilita su propia selección de tipos a partir de este catálogo global. Es posible que no veas todos los tipos listados aquí.

## Qué tipo de expediente debo usar?

Si no estás seguro de que tipo seleccionar, usa esta guía rápida:

| Necesito tramitar... | Tipo recomendado |
|----------------------|------------------|
| Un asunto que no encaja en ninguna categoría | **EEVAR** (Varios) |
| Una compra directa de insumos | **COMP** (Compras y Contrataciones) |
| Una licitación pública | **LICPUB** (Licitación Pública) |
| Una habilitación de local comercial | **HABI** (Habilitación Comercial) |
| Un permiso para una fábrica | **HIND** (Permiso Industrial) |
| Una obra pública municipal | **OBPUB** (Obra Pública) |
| Un reclamo de un vecino | **RECVE** (Reclamo Vecinal) |
| Una solicitud interna de RRHH (licencia, vacaciones) | **SRRHH** (Solicitudes RRHH) |
| Un trámite de catastro o tierras | **CATIE** (Catastro y Tierras) |
| Una denuncia de defensa del consumidor | **DECON** (Defensa del Consumidor) |

## Preguntas frecuentes

??? question "Puedo cambiar el tipo de expediente después de crearlo?"
    No. El tipo de expediente se define al momento de la creación y no se puede cambiar después. Por eso es importante elegir el tipo correcto desde el inicio.

??? question "Qué hago si mi trámite no encaja en ningún tipo?"
    Usa el tipo **EEVAR (Varios)**. Es un tipo genérico pensado para asuntos que no tienen una categoría específica.

??? question "El tipo TEST es para uso real?"
    No. El tipo **TEST (Testing Automatizado)** está reservado para pruebas del equipo de desarrollo. No debe usarse para trámites reales.
