# Tipos de Documento

El sistema incluye **61 tipos de documento** globales. Cada organización habilita su propia selección a partir de este catálogo. Los tipos se dividen en **3 categorías** según como se crea el contenido:

- **Documentos HTML** (41 tipos): se redactan en el editor de texto enriquecido del sistema.
- **Documentos importados** (18 tipos): se sube un archivo PDF externo.
- **Tipos internos** (2 tipos): los genera el sistema automáticamente y no están disponibles en el selector.

!!! info "Disponibilidad por organización"
    Cada organización habilita su propia selección de tipos a partir de este catálogo global. Es posible que no veas todos los tipos listados aquí.

## Tipos internos (2 tipos)

Estos tipos **no están disponibles en el selector** de creación de documentos. El sistema los genera automáticamente cuando corresponde.

| Sigla | Nombre | Descripción | Ejemplo de uso |
|-------|--------|-------------|----------------|
| PV | Pase | Se genera automáticamente al transferir un expediente | El sistema genera un PV al transferir |
| CAEX | Carátula | Se genera automáticamente al crear un expediente | El sistema genera un CAEX al crear expediente |

## Qué tipo de documento debo usar?

Si no estás seguro de que tipo seleccionar, usa esta guía rápida:

| Necesito... | Tipo recomendado |
|-------------|------------------|
| Escribir un informe técnico | **IF** (Informe) |
| Enviar una comunicación a otro sector | **NOTA** (Nota) |
| Adjuntar un PDF externo (plano, informe escaneado) | **IFGRA** (Informe Gráfico Importado) o **ANIMP** (Anexo Gráfico Importado) |
| Crear un acto administrativo firmado por el intendente | **DECRE** (Decreto) |
| Registrar una inspección | **AINSP** (Acta de Inspección) |
| Dejar constancia de una reunión | **ACT** (Acta) o **MIN** (Minuta) |
| Emitir un permiso de obra | **POBRA** (Permiso de Obra) |
| Habilitar un comercio | **HCOM** (Cert. Habilit. Comercio) |
| Adjuntar una factura de proveedor | **FACT** (Factura / Remito) |
| Adjuntar un contrato firmado externamente | **CONT** (Contrato) |

## Preguntas frecuentes

??? question "Puedo ver todos los tipos del catálogo?"
    No necesariamente. Cada organización habilita los tipos que necesita. Si un tipo no aparece en el selector al crear un documento, significa que tu organización no lo tiene habilitado.

??? question "Cuál es la diferencia entre un documento HTML y uno importado?"
    Un documento **HTML** se redacta directamente en el editor de texto de GDI. Un documento **importado** se crea subiendo un archivo PDF externo. Ambos pasan por el mismo proceso de firma.

??? question "Los tipos PV y CAEX aparecen en el selector?"
    No. Son tipos internos que el sistema genera automáticamente al transferir un expediente (PV) o al crear uno nuevo (CAEX). No se pueden crear manualmente.
